# 체육시설 예약 사이트

## 실행

예약 확인 문자와 예약 15분 전 알림을 보내려면 페이지와 API를 같은 서버에서 실행해야 합니다.

1. 알리고 계정에서 API 사용을 신청하고 API 키, 사용자 ID, 등록·인증된 발신번호를 준비합니다. 발신 잔액도 확인해주세요.
2. `.env`가 없으면 `.env.example`을 복사해 만듭니다. 관리자 계정은 로컬 `.env`에 설정되어 있습니다.
3. 알리고 문자를 사용하려면 `.env`에 `ALIGO_API_KEY`, `ALIGO_USER_ID`, `ALIGO_SENDER`를 추가합니다. `APP_ORIGIN`은 사이트 주소에 맞게 설정합니다. (로컬 실행 시 `http://localhost:3000`)
4. 프로젝트 폴더에서 `node server.js`를 실행하고 `http://localhost:3000`으로 접속합니다.

Windows PowerShell 로컬 실행 예시:

```powershell
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
# 알리고 문자를 사용할 경우 .env에 알리고 값을 입력합니다.
node server.js
```

`.env` 파일은 Git에 올라가지 않도록 제외했습니다. 문자 API 키와 관리자 비밀번호를 브라우저 코드나 공개 저장소에 넣지 마세요. 배포 시에도 서버가 `server.js`를 실행하도록 설정하고, 환경변수의 `APP_ORIGIN`을 실제 사이트 주소로 바꿔야 합니다. 정적 파일 호스팅만 사용하는 경우에는 SMS 발송과 관리자 인증이 동작하지 않습니다.

## 관리자 관리

`관리자` 탭에서 관리자 계정으로 로그인하면 예약·출결, 회원·포인트, 시설 운영/수용 인원, 비품명·재고·대여, 분실 신고 상태, A/S 처리 상태를 관리할 수 있습니다. 포인트 적립·차감, 노쇼 예약 제한, 일반·우선 예약 기간도 운영 정책 화면에서 변경할 수 있습니다.

## 포인트 및 출결

- 운영자는 `관리자 > 예약·출결`에서 예약 종료 후 이용 완료 또는 노쇼를 확정합니다.
- 이용 완료 1회당 100점, 누적 적립 500점마다 우선예약권 1장이 지급됩니다.
- 노쇼 1회당 100점 차감, 노쇼 누적 3회마다 예약이 24시간 제한됩니다.
- 우선예약권 1장을 사용하면 일반 7일 대신 최대 14일 전까지 예약할 수 있습니다. 8일 이후 예약에 자동 사용되며, 예약 취소 시 예약 시작 전이면 반환됩니다.
- 예약·회원 정보는 현재 브라우저의 `localStorage`에 저장됩니다. 운영자 출결 처리는 예약 데이터가 있는 같은 브라우저에서 해야 합니다.
